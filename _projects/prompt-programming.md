Prompt Programming is a platform for studying and supporting computational problem solving with generative AI. It integrates multi-turn natural-language prompting, direct code editing, code execution, and automated testing within the same workflow.

Across multiple university deployments, we have used the platform with more than 2,100 students to study how people combine prompting with code editing, debugging, verification, and different interaction modalities when solving programming tasks.

<img class="project-detail-image" src="/assets/img/projects/prompt-programming.png" alt="Prompt Programming interface screenshot" />

Our studies show that prompting and editing play complementary roles. Prompting is frequently used to generate or restructure solutions, while editing supports small, targeted repairs after execution or verification reveals a problem. The platform also serves as an experimental environment for studying how programming practices change as code-generating models become increasingly capable.

Recent work using the platform includes [Interleaving Natural Language Prompting with Code Editing for Solving Programming Tasks with Generative AI Models](https://doi.org/10.1145/3803400.3809312) (ITiCSE 2026), [Say What? Examining Text and Voice Input Modalities for Prompt-Based Programming in Computing Education](https://doi.org/10.1145/3803400.3809397) (ITiCSE 2026), [Understanding Student Perceptions, Mistakes, and Debugging Approaches when Solving Natural Language Programming Tasks](https://doi.org/10.1145/3765964.3811639) (ICER 2026), and [When AI Is Wrong on Purpose: How Students Respond to Buggy GenAI Code](https://doi.org/10.1145/3765964.3811667) (ICER 2026).

You can read the main paper on [ACM Digital Library](https://doi.org/10.1145/3724363.3729094), access the preprint on [arXiv](https://arxiv.org/abs/2503.04267), and try the system on the [Prompt Programming website](https://www.promptprogram.org).
